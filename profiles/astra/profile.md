# Astra consumer profile

Local consumer profile for Fallenproud/skill-hub-registry. This is a proposed upstream profile, not an upstream mutation or canonical skill definition. Definitions are pinned and hash-verified from `skills/` through the compiled index. Discovery never grants execution. Activation is bound to the reviewed content hash and becomes inactive after a changed definition.

Astra owns compatibility, approvals, delegation, execution, persistence and audit. The first qualified binding is `agent-archify-001` to the local Archify renderer. Other packages remain inspectable and blocked until an explicit runtime binding is qualified. No shell commands from SKILL.md are automatically executed.
