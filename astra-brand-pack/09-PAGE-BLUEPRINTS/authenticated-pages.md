# 24 — Canonical App Shell

The fundamental product shell is:

```text
┌───────────────────────────────────────────────────────┐
│ TOP RUNTIME BAR                                       │
├─────────────┬──────────────────────────┬──────────────┤
│             │                          │              │
│ LEFT NAV    │     MAIN WORKSPACE       │  INSPECTOR   │
│             │                          │              │
│             │                          │              │
│             │                          │              │
│             │     TASK COMPOSER        │              │
│             │                          │              │
└─────────────┴──────────────────────────┴──────────────┘
```

These are the five core layout primitives:

1. Runtime Bar
2. Navigation
3. Main Workspace
4. Composer
5. Inspector
