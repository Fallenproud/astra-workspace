# 17 — Canonical Radius

Recommended:

`sm 10px`

`md 14px`

`lg 18px`

`xl 24px`

Avoid extreme pillification.

Pills belong to:

* compact state
* filters
* metadata
* chips

not entire product panels.

---



# 18 — Canonical Border System

Borders are more important than shadows in Astra.

Hierarchy:

### B0

No border.

### B1

Subtle structural boundary.

### B2

Standard component boundary.

### B3

Active/selected green boundary.

### B4

Focused command/action boundary.

Use opacity variations rather than constantly changing hue.

---



# 19 — Shadow System

Shadows should be almost invisible.

Purpose:

* separate layers
* establish elevation
* subtly reinforce modal hierarchy

Not:

* decorate cards
* create fake depth everywhere

---



# 22 — Iconography

Canonical style:

* simple outline icons
* consistent stroke
* approximately 1.5–2px
* geometric
* minimal

Primary categories:

* Home
* Project
* Run
* Artifact
* Skill
* Workflow
* Integration
* Settings
* Context
* Model
* Provider
* Tool
* Logs
* Resources
* Search
* Upload

Lucide is a strong implementation baseline.
