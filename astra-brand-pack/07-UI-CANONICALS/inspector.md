# 33 — Inspector Canonical

The right panel is contextual.

It can transform based on selected object.

Examples:

### Task

Task configuration

### Run

Run state + telemetry

### Project

Project metadata

### Artifact

Preview + metadata

### Skill

Compatibility + permissions

### Workflow

Execution configuration

The Inspector should never become a static redundant sidebar.
