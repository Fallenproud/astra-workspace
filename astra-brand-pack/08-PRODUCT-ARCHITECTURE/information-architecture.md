# Information architecture

Astra owns projects, runs, history, artifacts, approvals, skills activation and workflows. Execution adapters are replaceable. Codex app-server is one backend; Responses API is independent.

Connect → Configure → Create → Run → Observe → Refine → Ship.

Models are not accounts. Skills are canonical definitions, not automatically trusted runtime code. Discovery never enables execution. Local activation binds a qualified content hash to a supported runtime.
