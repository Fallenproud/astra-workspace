# AI handoff

Read the canonical source and acceptance checklist before extending the product. Astra owns orchestration, persistence, runtime bindings and approvals. Responses and Codex are independent execution adapters. Skill Hub is read-only upstream; only qualified native skills become executable. Development must remain a deterministic, network-free model simulator with real local orchestration.

Future expansion includes team identity, collaboration, hosted waitlist, OAuth connectors, arbitrary DAG workflow execution and deployment endpoints. Do not advertise these as shipped.
