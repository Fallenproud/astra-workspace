# ASTRA WORKSPACE — CANONICAL BRAND PACK

### Canonical Identity System / Product Design System / Handoff Standard — v1.2

The current reference establishes a much cleaner identity than our earlier aurora-heavy version. **Astra is now primarily obsidian, architectural, quiet, monochrome-green software**; atmospheric arcs and glass depth support the product rather than becoming the product.

---

## 00 — Canonical Brand Core

**Official product name:**
**Astra Workspace**

**Primary positioning:**
AI Workspace / AI Agent Platform / Multi-Model AI Control Plane

**Canonical purpose statement:**
**Give Astra a place to work.**

**Supporting product statement:**
Create projects, run tasks, manage artifacts, activate skills, build workflows, connect integrations, and operate AI work from one persistent environment.

**Product promise:**
**Turn ideas into real work.**

**Functional promise:**

`Connect → Configure → Create → Run → Observe → Refine → Ship`

Astra is specifically **not positioned as another chatbot**.

It is a persistent operational environment where AI can actually perform work.

---

# 01 — Brand Philosophy

The identity rests on six principles.

### 01.1 Quiet capability

The interface should look powerful without constantly telling the user that it is powerful.

### 01.2 Operational clarity

State, actions, tools, context, models, and execution should be understandable.

### 01.3 Human ambition + machine leverage

The product is not about replacing the user's intent.

The user defines the objective.

Astra provides execution leverage.

### 01.4 Architectural minimalism

Avoid visual decoration without structural purpose.

### 01.5 Truthful software

Never fabricate:

* provider connectivity
* model availability
* system readiness
* token usage
* execution state
* tools
* artifacts
* integrations

### 01.6 Extensible by design

The visual and product systems must survive future capabilities without requiring a rebrand.

# 08 — Semantic Color Rules

| Meaning     | Canonical treatment       |
| ----------- | ------------------------- |
| Ready       | Green                     |
| Running     | Green + controlled motion |
| Selected    | Green border / soft fill  |
| Success     | Bright green              |
| Pending     | Gray                      |
| Disabled    | Dim gray                  |
| Information | White/gray first          |
| Warning     | Muted amber               |
| Error       | Restrained red            |
| Destructive | Red only                  |
| Focus       | Green border/ring         |

Do not use different bright colors for every state.

Astra is deliberately chromatically disciplined.

# 49 — The Five Hardest Brand Locks

If everything else disappeared, preserve these five things:

**1. `Give Astra a place to work.`**

**2. The geometric green Astra mark.**

**3. Obsidian + graphite + monochrome green visual system.**

**4. Desktop operational workspace architecture.**

**5. Projects → Runs → Artifacts → Skills → Workflows → Integrations.**

Those five alone are enough to reconstruct Astra's identity.

# 50 — Canonical Brand Definition

The final condensed identity is:

> **Astra Workspace is a premium, desktop-first AI operating workspace built around an architectural obsidian interface, a restrained monochrome-green identity, persistent projects and execution state, and a modular system for models, runs, artifacts, skills, workflows and integrations. Its visual language communicates quiet capability rather than spectacle, and its defining promise is simple: Give Astra a place to work.**

That is the brand pack hierarchy I would now treat as the **Astra canonical source of truth**.
