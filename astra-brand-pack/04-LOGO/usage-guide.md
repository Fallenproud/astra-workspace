# 10 — Canonical Logo

The current logo direction is an **angular folded Astra A**.

It should feel:

* geometric
* architectural
* dimensional
* lightweight
* directional
* technical

The green gradient creates depth without requiring complex textures.

---



# 11 — Logo Family

Canonical package should contain:

### Primary

`Astra Workspace` horizontal lockup

### Mark

Astra geometric A

### Monochrome

* green
* white
* black

### Icon

* 16
* 32
* 48
* 64
* 128
* 256
* 512
* 1024

### Product surfaces

* favicon
* Windows app icon
* macOS app icon
* PWA icon
* GitHub avatar
* social avatar

---



# 12 — Logo Clear Space

Minimum clear space:

**½ the height of the inner Astra mark opening.**

Never allow:

* navigation text
* panel borders
* artwork
* text
* other logos

to invade this region.

---



# 13 — Logo Restrictions

Never:

* rotate it
* skew it
* outline it unnecessarily
* add purple unless an explicit edition permits it
* apply rainbow effects
* add heavy glow
* use it inside arbitrary circles
* distort its proportions
* replace the logo with a generic A
